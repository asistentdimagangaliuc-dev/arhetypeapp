## 1. Методика

**Первоисточники-книги (легальный поиск по тексту, без скачивания полных текстов).**
- Поиск Internet Archive по тексту через Open Library: `https://openlibrary.org/search/inside.json?q="<фраза>"`; из выдачи брались только совпадения в нужном экземпляре. Экземпляры:
  - **IA-MP** — Mark & Pearson, *The Hero and the Outlaw*, 2001: https://archive.org/details/herooutlawbuildi0000mark (только для print-disabled, поиск по тексту открыт);
  - **IA-AHW** — Pearson, *Awakening the Heroes Within*, 1991: https://archive.org/details/awakeningheroesw0000pear ;
  - **IA-HW** — Pearson, *The Hero Within*, 1989 (ISBN 006254862X), экземпляр библиотечной выдачи: https://archive.org/details/herowithinsixarc00pear ;
  - **IA-SOL** — Solomon, *Consumer Behavior*, 11-е изд., 2014: https://archive.org/details/consumerbehavior0000mich_edi11 (и изд. 2018 `consumerbehavior0000solo_n4t7`).
- Ограничения: поиск только по точной фразе; в выдаче не больше 20 книг, поэтому частые фразы («primary colors», «Jolly Green Giant») не находят нужную книгу — это «не проверено», а не «нет в книге». Текст читался цепочкой: следующий запрос строился из конца предыдущего фрагмента. Номера страниц — по колонтитулам во фрагментах, если попали.
- Русские издания: оглавление «Бомборы» (PDF Эксмо, получено через WebFetch, текст извлечён `pdftotext`), ознакомительные фрагменты на Литрес («Бомбора», МИФ).

**Веб-источники.**
- Все 174 уникальных URL из шести карточек проверены `curl` (статус и итоговый адрес), затем скачаны и переведены в текст; утверждения сверялись поиском по тексту страницы. Заблокированные для `curl` адреса повторно открывались через WebFetch.
- YouTube: число подписчиков бралось из шапки канала (строка с собственным handle канала, а не из блока «рекомендованные каналы»).
- Википедия (ru/en) — как вторичный источник для дат, статусов брендов и правовых статусов.
- WebSearch — 2 запроса (кампания Diesel «Be Stupid»; закрытие музыкальных каналов MTV).
- Персональные данные в запросы не включались. Пиратские копии не использовались.

**Сигнал координатора (учтён).** Соседний проверяющий (карточки 07–12) нашёл, что часть фраз из издания «Бомборы», приписанных Марк и Пирсон, — из «Предисловия от российского издателя» (подпись — И. Романов). Проверены все опоры карточек 01–06 на «Бомбору» и на r14 пп. 1.1/1.6:
- BMW «олицетворяющий архетип Бунтаря» — **из предисловия издателя** (во фрагменте Литрес стоит до раздела «Предисловие» авторов, после подписи «Игорь Романов…»). Исправлено в карточках 04 и 05.
- Ivory «дарит обновление, чистоту и невинность» — **основной текст авторов** (после авторского «Предисловия», совпадает с OCR оригинала «it is about renewal, purity, and…»). Атрибуция сохранена, в карточке 01 добавлена пометка.
- Названия частей и глав «Бомборы» взяты из оглавления издателя — это не цитаты, а названия; подтверждены.
- Девиз Шута в карточках 01–06 не упоминается; правка не требуется.

**Легенда вердиктов:** подтверждено / исправлено / помечено ⚠ / удалено / дополнено (новый факт с источником).
