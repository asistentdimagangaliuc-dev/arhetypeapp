## 1. Методика

1. **Книги — только легальный поиск по тексту.** Полнотекстовый поиск Open Library (`openlibrary.org/search/inside.json`) по библиотечным экземплярам Internet Archive с выдачей по записи. У всех использованных экземпляров `access-restricted-item: true` (проверено через `archive.org/metadata`). Полные тексты не скачивались. Ограничение: поиск возвращает общее число листов скана, а не страницу фрагмента, поэтому номера страниц так не подтверждаются.
2. **КиберЛенинка.** Страницы статей закрыты капчей. Текст получен через поисковый API сайта (`cyberleninka.ru/api/search`), который возвращает OCR-фрагменты статей. Списки литературы видны только тогда, когда попадают во фрагмент.
3. **Прямые адреса:** WebFetch и curl. Для недоступных страниц — CDX и копии Wayback Machine по известному адресу.
4. **Каталоги и метаданные:** Crossref, Unpaywall, OpenAlex; Open Library (записи из MARC Библиотеки Конгресса).
5. **WebSearch:** 12 запросов. Тринадцатый был отклонён: квота на ход исчерпана, она общая для всех агентов. После этого работа шла только через WebFetch по прямым адресам и поиск по тексту конкретных книг. Страницы выдачи поисковиков не открывались.
6. **Ограничения сети:** Google Books API (квота 0), Semantic Scholar (429), Elsevier API (нужен ключ), ScienceDirect (403), API Википедии (429; статьи читались через WebFetch), НЭБ (403 и сброс соединения), поиск РГБ (без JavaScript данных нет), `cmd-journal.hse.ru` (сброс соединения через прокси).
7. **Неавторизованные копии** не использовались. psytests.org попадал в выдачу, но как источник не использовался. Личных данных в запросах не было.
