## 1. Методика

1. **Книга Марк и Пирсон (2001) и другие книги.**
   - Только легальный полнотекстовый поиск Open Library (`openlibrary.org/search/inside.json`) по библиотечным экземплярам Internet Archive. Ответ — короткие OCR-фрагменты; полный текст, hOCR, PDF и djvu не скачивались.
   - Экземпляры: `herooutlawbuildi0000mark` (M&P 2001), `awakeningheroesw0000pear` (Пирсон 1991), `herowithinsixarc00pear` (Пирсон 1986), `invisiblepartner0000wood` (*The Invisible Partnership*), `breakthroughthin0000sout` (Souter 2007), `isbn_9780739173268` (Lexington 2012).
   - Прямые запросы `curl` к API часто обрывались на уровне туннеля (connection reset), поэтому основная часть запросов шла через WebFetch. Поиск внутри книги на archive.org (`fulltext/inside.php`) для экземпляра с ограниченным доступом недоступен («Item not available»).
   - Ограничение метода: поиск возвращает только 20 лучших книг. Если фраза частая, M&P может не попасть в выдачу. Такие случаи помечены «не воспроизведено», а не «опровергнуто».
2. **Веб-источники.** Страницы открывались напрямую (`curl` с описательным User-Agent, затем извлечение текста скриптом; или WebFetch). WebSearch не использовался ни разу; страницы выдачи поисковиков не открывались.
3. **Википедия.** Сырой текст статей — через `index.php?action=raw` с паузами. Один раз сработало ограничение частоты (HTTP 429) — запрос повторялся позже.
4. **Правовой статус.**
   - Список «иностранных агентов» сверен по сырому тексту статьи Википедии «Список «иностранных агентов» (Россия)». Последняя дата внесения в списке — 18.09.2026, это совпадает с c04. Проверка — по фамилиям всех 32 русскоязычных персон шести карточек.
   - Официальный реестр Минюста недоступен: страница раздела — обрыв TLS (SSL_ERROR_SYSCALL), корень сайта — редирект 302.
   - Уголовные дела, санкции и запреты въезда — по статьям Википедии о персонах. Везде стоит пометка «перед использованием нужна юридическая проверка».
5. **YouTube.** Число подписчиков — из шапки канала, дата последнего ролика — из RSS (`feeds/videos.xml`).
6. **Duarte, Zuffa, Ashofteh (2026).** Открытый PDF журнала; текст извлечён `pdftotext`, страница с табл. 3–4 дополнительно отрисована и сверена визуально.
7. **Список К. Голдена.** Перепечатка на jaced.com (08.01.2014) открыта напрямую. Страница прямо называет автора — «Carl Golden» со ссылкой на soulcraft.co. Оригинал недоступен: домен не резолвится, архив как обход не использовался. Текст разделов для 07–12 сверен с карточками дословно.
8. **Правила.** Нумерация, висячие ссылки, неиспользованные источники, длина цитат (≤ 25 слов) и число столбцов в таблицах проверены скриптом до и после правок. Отдельно проверены ссылки на неавторизованные копии (по списку доменов) и рекомендации по проектированию продукта (по ключевым словам).

- «perfectionism, bad solutions» — 0 книг;
