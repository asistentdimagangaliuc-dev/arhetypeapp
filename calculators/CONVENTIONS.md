## API калькулятора
```python
def calculate(b: BirthInput, **options) -> dict: ...
```
Результат — JSON-сериализуемый словарь с ключами:
- `method`
- `variant` — школа или вариант расчёта
- `inputs_used`
- `warnings: list[str]`
- результаты метода
- `steps` — промежуточные шаги расчёта, чтобы агент мог показать пользователю, как получен результат

Python 3.11+, аннотации типов, комментарии и докстринги на русском. Без новых внешних зависимостей; если без них никак, напишите об этом в отчёте.

**Подводный камень lunar-python.** Библиотека считает введённое время пекинским (UTC+8), в том числе при определении солнечных терминов (цзеци). Для рождений вне Китая нужно либо передавать ей время, пересчитанное в UTC+8, либо считать цзеци самостоятельно через `find_sun_longitude`.

## Шаблон файла `knowledge-base/NN-<slug>.md` (пишется на русском, оригинальные термины в скобках)
1. **Суть и школы.** Варианты расчёта, какой принят по умолчанию и почему.
2. **Входные данные.** Обязательные и необязательные; что меняется, если неизвестно время или место.
3. **Алгоритм.** Пошаговый и настолько точный, чтобы ИИ-агент мог посчитать вручную без кода, плюс псевдокод.
4. **Справочные таблицы.** Полные, без «и т.д.».
5. **Выход.** JSON-схема результата.
6. **Контрольные точки.** Инварианты и самопроверки результата, типичные ошибки, граничные случаи.
7. **Примеры.** Не меньше трёх полностью разобранных примеров со всеми промежуточными шагами, включая T1–T4 и граничный случай. Каждый сверен с независимым источником, сверка отмечена.
8. **Ключи интерпретации.** По 1–2 строки на каждый элемент, таблицей.
9. **Источники.** URL и оценка надёжности: первоисточник / школа / калькулятор / вторичный.

Ничего не выдумывать. Всё, что не удалось подтвердить, помечать «⚠ не подтверждено». Расхождения между школами описывать явно.
