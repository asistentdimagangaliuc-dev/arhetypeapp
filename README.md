# arhetypeapp — база знаний и калькуляторы расчётов по дате рождения

- **[REPORT.md](REPORT.md)** — отчёт о проделанной работе: проверки и тесты по каждой методике, открытые вопросы, план.
- **[knowledge-base/README.md](knowledge-base/README.md)** — точка входа для ИИ-агента. Там чек-лист вопросов пользователю, маршрутизация по методам, шаблон ответа и ограничения.
- **knowledge-base/00–19** — 20 модулей:
  - нормализация времени;
  - Ба-цзы, Цзы Вэй Доу Шу, Девятизвёздная Ки и Гуа;
  - Human Design, Gene Keys, западная астрология, Джйотиш;
  - квадраты Пифагора и Александрова, Матрица судьбы, нумерология;
  - Таро, Ло Шу и ведическая нумерология, Цолькин;
  - соционика и эннеаграмма, Сюцай;
  - Ци Мэнь Дунь Цзя, Да Лю Жэнь;
  - западная и восточная прогностика.

  Каждый модуль содержит алгоритм, полные таблицы, контрольные точки, разобранные примеры, источники и протокол независимой проверки.
- **knowledge-base/test-subjects.md** — сводка результатов всех методов для эталонных персон T1–T4.
- **calculators/** — эталонные калькуляторы на Python (Swiss Ephemeris, tzdb) с тестами.

```bash
python3 -m venv .venv && .venv/bin/pip install -r calculators/requirements.txt
.venv/bin/python -m pytest
.venv/bin/python -m calculators all --date 1990-05-15 --time 14:30 --place Москва --gender female --name "Иванова Анна Сергеевна"
```
