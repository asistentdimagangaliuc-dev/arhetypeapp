# Источники базы знаний

Каждый документ метода содержит раздел «Источники» с оценкой надёжности каждого источника и раздел «Протокол проверки» (что именно было независимо перепроверено). Здесь — сводный индекс всех процитированных URL по модулям (сгенерирован `calculators/tools/build_sources.py`).

Всего уникальных ссылок по модулям: **376**.

**Шкала надёжности, используемая в документах:**

| Уровень | Что это | Как использовать |
|---|---|---|
| первоисточник | книга/сайт основателя системы, официальный калькулятор школы, астрономические службы (USNO, HKO), tzdb | правило считается установленным |
| школа | сайты и курсы признанных практиков школы | правило школы; при расхождениях — указывать вариант |
| калькулятор | выдача известных калькуляторов (сверка чисел) | годится для тестовых векторов, не для правил |
| вторичный | статьи, блоги, форумы, журналистика | только как подсказка; помечено ⚠, если не подтверждено |

Ограничения проверки: часть сайтов (astro.com / Astro-Databank, ladini.ru, некоторые китайские ресурсы) была недоступна из среды исследования (защита от ботов, HTTP 503); соответствующие утверждения в документах подтверждены через копии/другие источники или помечены ⚠.
