# 08. Квадрат Пифагора (психоматрица)

Калькулятор: `calculators/pythagoras.py` (`calculate(b, post2000_rule=..., day_digit=...)`).
Тесты: `calculators/tests/test_pythagoras.py`, 48 pytest-кейсов; 26 векторов (дат) взяты из независимых публикаций (все URL перепроверены 14.10.2026, см. «Протокол проверки»).

> Документ описывает **классическую популярную психоматрицу**: рабочие числа, раскладку цифр по 9 ячейкам, 8 линий и ключи по количеству цифр.
> Доработки А. Ф. Александрова сюда **не входят**: переходы цифр (11↔8, 22↔4, 6↔7, 55→9 и 99→5), «сильные линии» по периодам тысячелетия и дополнение квадрата новыми цифрами. Они описаны в **документе 09 «Квадрат Александрова»** (`calculators/alexandrov.py`). Здесь на них только ссылки.

## 1. Суть и школы

**Психоматрица** (квадрат Пифагора) — это таблица 3×3, построенная только по дате рождения. По дате считают четыре **рабочих (дополнительных) числа**. Затем все цифры даты и рабочих чисел, кроме нулей, раскладывают по ячейкам: в ячейку 1 идут все единицы, в ячейку 2 все двойки и так далее. Качество, за которое отвечает ячейка, оценивается по количеству цифр в ней. Сумма количеств в строке, столбце или диагонали даёт силу соответствующей **линии**.

Античного первоисточника у метода нет. В русскоязычной традиции он сложился в 1990–2000-х годах, прежде всего по книгам А. Ф. Александрова. Все популярные сайты и СМИ пересказывают одну и ту же схему расчёта. Ниже перечислены места, где школы расходятся.

## 3. Алгоритм

### 3.1. Рабочие числа (классика, по умолчанию)

1. Запишите дату как ДД.ММ.ГГГГ и **сложите все цифры**. Нули сумму не меняют. Это **1-е число** (Ч1).
2. **2-е число** (Ч2) — сумма цифр Ч1, **один проход**: 29 → 11, 28 → 10, 39 → 12. Дальше не сворачивать. Если Ч1 однозначное (бывает только с 2000 г.), то Ч2 = Ч1 (Трошин: 5.11.2000 → 9, 9).
3. **3-е число** (Ч3) = Ч1 − 2 × *k*, где *k* — первая **ненулевая** цифра дня (для 15 → 1, 30 → 3, 05 → 5). Если результат отрицательный, берётся **модуль**: 9 − 10 = −1 → 1. Ноль допустим: 10 − 10 = 0. Отрицательное Ч3 бывает у лет с малой суммой цифр: в 1800–2099 только с 2000 г., а вообще и раньше (годы 1–7, 1000–1006, 1100–1105, 1200–1204 …; например 30.01.1000 → 5 − 6 = −1 → 1).
4. **4-е число** (Ч4) — сумма цифр Ч3, один проход: 28 → 10, 29 → 11. Если Ч3 однозначное, Ч4 = Ч3 (Александров: «четвёртое число совпадает с ним»), например 2 → 2, 0 → 0.

### 3.2. Квадрат

5. Выпишите все цифры даты и все цифры Ч1, Ч2, Ч3, Ч4. **Нули отбросьте.** Ведущие нули дня и месяца тоже не учитываются, ячейки для 0 нет.
6. Посчитайте, сколько раз встречается каждая цифра от 1 до 9, и впишите эти цифры в ячейки:

```
┌──────┬──────┬──────┐
│  1   │  4   │  7   │   строка «Цель»          (1,4,7)
├──────┼──────┼──────┤
│  2   │  5   │  8   │   строка «Семья»         (2,5,8)
├──────┼──────┼──────┤
│  3   │  6   │  9   │   строка «Стабильность»  (3,6,9)
└──────┴──────┴──────┘
 «Само-  «Быт»  «Талант»     диагонали: 1-5-9 «Духовность», 3-5-7 «Темперамент»
 оценка» (4,5,6) (7,8,9)
 (1,2,3)
```

7. **Линии.** Количество цифр в линии = сумма количеств её трёх ячеек (numerolog.ru: «цель = единицы + четверки + семерки»).
8. **Баланс диагоналей** (Зорина 2017): если темперамент больше духовности, человек «более склонен к материальной стороне». Если меньше — к духовной. Если равны — стороны уравновешены.
9. «Номер жизни» по Александрову: общее количество цифр в квадрате («в расчете — 14 цифр, значит, данная душа проживает 14-ю жизнь… больше 15 цифр не будет»). Трактовка эзотерическая, калькулятор просто выводит `digits_total`.

### 3.3. Псевдокод

```text
digits(n)      = десятичные цифры |n|
dsum(n)        = сумма digits(n)                     # один проход!
D              = цифры строки f"{день:02}{месяц:02}{год:04}"
Ч1 = sum(D)
Ч2 = dsum(Ч1)
k  = день // 10 if день >= 10 else день              # day_digit="first_nonzero"
     (day_digit="literal":  k = день // 10)
Ч3 = |Ч1 − 2k|                                        # post2000_rule="plus19" и год>=2000: Ч3 = Ч1 + 19
                                                      # post2000_rule="sidorova": Ч2 = 2 (год<2000) или 19,
                                                      #   Ч3 = Ч1 − 2 или Ч1 + 19 (любой год)
Ч4 = dsum(Ч3)
ALL = [x for x in D if x≠0] + EXTRA + [x for n in (Ч1,Ч2,Ч3,Ч4) for x in digits(n) if x≠0]
count[d] = ALL.count(d), d = 1..9
line[L]  = Σ count[d] для d ∈ L,  L ∈ {147, 258, 369, 123, 456, 789, 159, 357}
```

`EXTRA` пуст в классике. В варианте `add_1_9` это [1, 9], в варианте `year_1999` — цифры 1999 и N.

### 3.4. Варианты для рождённых после 2000 г. (не по умолчанию)

Все варианты, кроме `sidorova`, включаются только при годе ≥ 2000. При более раннем годе опция игнорируется, и выдаётся предупреждение. `sidorova` задан источником для всех дат (−2 до 2000 г., +19 с 2000 г.).

## 6. Контрольные точки

**Инварианты** (все проверяются в тестах):
- Цель + Семья + Стабильность = Самооценка + Быт + Талант = `digits_total`.
- `digits_total` = число ненулевых цифр даты + ненулевых цифр Ч1…Ч4 (+ `extra_digits` в вариантах).
- Ч2 = сумма цифр Ч1, Ч4 = сумма цифр Ч3 (один проход). Для дат 1800–2099 Ч2 и Ч4 ≤ 12.
- В классике `digits_total` ≤ 15. Для дат 1900–1999 Ч3 ≥ 0, и в квадрате есть хотя бы одна 1 и одна 9.
- Ячейки 1–9 и 8 линий всегда присутствуют; пустая ячейка = 0 цифр = отдельная трактовка.

**Типичные ошибки:**
1. Свернуть Ч2 = 11 в 2 или Ч4 = 10 в 1. У Александрова 2-е и 4-е числа остаются двузначными (Горбачёв 19 **10** 15 6, Ленин 21 3 19 **10**); Трошин называет сведение к однозначному «не вполне корректным». Исключение не нужно: если Ч1 = 10, то Ч2 = 1 + 0 = 1 — это обычная сумма цифр (01.01.2015).
2. Удвоить 0 для дня 01–09. По умолчанию удваивается первая ненулевая цифра, пример Александрова 6.9.1973 → 23.
3. Оставить отрицательное Ч3 со знаком или «обнулить». Правильно — модуль: 09.01.2002 → 4.
4. Вписать в квадрат нули или «искусственные» ведущие нули (Трошин: «Искусственно добавлять нули неправильно»). Нули не вписываются никогда.
5. Забыть цифры рабочих чисел. В квадрат идут **и дата, и все четыре числа**: у 01.01.2000 четвёрки (44) — это цифры Ч1 и Ч2.
6. Перепутать «строки» и «столбцы» при транспонированной раскладке (Афиша). Опирайтесь на наборы цифр линий.
7. Взять дату по старому стилю для рождённых в России до 1918 г.
8. Молча применить поправку «+19» или «1 и 9». Она меняет 3-е и 4-е числа и добавляет цифры (см. 3.4), поэтому вариант всегда указывается в `variant`.

**Граничные случаи:** 29 февраля (обычная дата, T3; несуществующая дата вроде 29.02.2001 — ошибка `ValueError`); день 01–09 (T2, 06.09.1973); Ч1 однозначное (5.11.2000 → 9, 9); Ч3 < 0 (09.01.2002; до 2000 г. — 30.01.1000 → 1); Ч3 = 0 (05.01.2020 → 10 1 0 0); Ч1 = 10 → Ч2 = 1 (01.01.2015); даты до 1918 г. (T4); год < 1000 (15.06.988 → 37 10 35 8, ведущий ноль года не пишется и не влияет).

**Самопроверка ручного расчёта (выполнять всегда):**
1. Ч1 = сумма **всех** цифр даты; пересчитайте второй раз в обратном порядке.
2. Ч2 = сумма цифр Ч1 **один раз**; Ч4 = сумма цифр Ч3 один раз; если Ч3 однозначное, Ч4 = Ч3.
3. Удвоенная цифра — первая ненулевая цифра **дня** (не месяца и не года); Ч3 ≥ 0.
4. Число цифр в квадрате = число ненулевых цифр даты + число ненулевых цифр Ч1–Ч4. Для T1: 6 + 5 = 11.
5. Цель + Семья + Стабильность = Самооценка + Быт + Талант = число цифр в квадрате.
6. Число цифр ≤ 15 (для дат 1000–2999), ≥ 5.
7. Для дат 1900–1999 есть хотя бы одна 1 и одна 9; если нет — ошибка в расчёте.

## 8. Ключи интерпретации (кратко)

| Элемент | Что показывает |
|---|---|
| 1-е число | Качества, которые нужно усилить, чтобы достичь цели (Рыбакова, в книге Александрова) |
| 2-е число («ведущее») | Ведущее качество и основная цель человека. Пример: 11 — «власть, гордыня», стать лидером или преодолеть гордыню [А] |
| 3-е и 4-е числа | Качества, данные от рождения, «во многом определили родители» [А] |
| Цифры даты | Набор качеств, которыми человек пользуется для развития ведущих [А] |
| Ячейка 1 | Характер, воля, стремление к власти |
| Ячейка 2 | Энергия: «вампир» (мало) или «донор» (много) |
| Ячейка 3 | Интерес к наукам: гуманитарные (мало) или точные (много) |
| Ячейка 4 | Здоровье, тело |
| Ячейка 5 | Логика и интуиция, умение планировать |
| Ячейка 6 | Склонность к физическому труду, «золотые руки» |
| Ячейка 7 | Везение, талант, «защита от неудач» |
| Ячейка 8 | Чувство долга, терпимость, доброта к близким |
| Ячейка 9 | Память, ум; при 3+ — «ясновидение» |
| Цель (1-4-7) | Целеустремлённость, умение отстаивать взгляды |
| Семья (2-5-8) | Качество семьянина, стремление иметь семью |
| Стабильность (3-6-9) | Привычки, привязанности, отношение к переменам |
| Самооценка (1-2-3) | Желание выделиться из толпы |
| Быт (4-5-6) | Готовность материально обеспечивать себя и семью |
| Талант (7-8-9) | Сила таланта: чем больше цифр, тем сильнее, до 5 |
| Духовность (1-5-9) | Стремление к духовному; 6+ — фанатизм |
| Темперамент (3-5-7) | Плотские интересы, темперамент в интимной жизни |
| Баланс диагоналей | Темперамент больше духовности — «материальная» направленность; меньше — «духовная»; равны — равновесие |
| `digits_total` | «Номер жизни» (эзотерика, Александров), не больше 15 |

**Совместимость (кратко, по Александрову).** Для семьи сравнивают линии партнёров.
- **Цель:** лучше, когда один сильнее другого, а цели дополняют друг друга.
- **Самооценка и Быт:** влияют на стабильность семьи.
- **Диагонали:** желательно, чтобы соотношение темперамент/духовность у партнёров совпадало или было одного знака.
- **Энергия:** «донору» (2222+) подходит «2-нет»/«2»; «экстрасенсу» (222) — только «22»; «22» совместима с любой.

Детальные правила совместимости и переходы цифр относятся к методу Александрова (док. 09).

> Психоматрица — нумерологическая (эзотерическая) практика без научного подтверждения. Ключи описывают традицию метода, а не проверенные свойства личности. Пустые ячейки у рождённых после 2000 г. не означают «отсутствие способностей» (kp.ru, numerolog.ru).
