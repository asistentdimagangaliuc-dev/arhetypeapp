# 10. Матрица судьбы (метод 22 арканов, школа Натальи Ладини)

Калькулятор: `calculators/destiny_matrix.py`. Тесты: `calculators/tests/test_destiny_matrix.py`.
CLI: `python -m calculators destiny_matrix --date 1990-05-15 [--opt on_date=2026-10-14] [--opt reduction=minus22]`.

---

## 1. Суть и школы

Матрица судьбы (Matrix of Destiny, «октаграмма») — авторская нумерологическая система, созданная на основе 22 старших арканов Таро. Метод приписывают Наталье Ладини. Из даты рождения строятся два наложенных квадрата: личный (ромб) и родовой. Это восьмиконечная звезда с центром. Каждая точка — аркан от 1 до 22. Кроме вершин, считаются внутренние точки линий, денежный канал, канал отношений, кармический хвост, предназначения, карта здоровья (чакры) и внешнее возрастное кольцо от 0 до 80 лет.

Научного обоснования у метода нет. Это символическая система самопознания, а не прогноз и не медицинский инструмент. Карта здоровья описывает эзотерические «зоны внимания» и не заменяет врача.

**Первоисточник.** Книги и курсы Н. Ладини недоступны для сверки (сайт ladini.ru не открылся). Поэтому схема восстановлена по крупнейшему русскоязычному калькулятору, который прямо называет метод «методом Натальи Ладини» (matrica-sudby.ru), и по независимым калькуляторам и разборам. Все формулы ниже проверены на **опубликованных полных схемах с числами** (см. раздел 7 и тесты).

## 3. Алгоритм

### 3.1 Свёртка (функция `R(n)`)

* По умолчанию: **пока n > 22, n = сумма цифр n**. Числа 1–22 не меняются, **22 остаётся 22**.
  Примеры: 23 → 5, 25 → 7, 28 → 10, 31 → 4, 39 → 12, 47 → 11, 99 → 18, 154 → 10.
* Вариант `minus22`: пока n > 22, n = n − 22 (23 → 1, 42 → 20, 62 → 40 → 18).
* Сворачивается **каждое промежуточное значение**: в следующих формулах участвуют только числа 1–22.
  Ноль в Матрице получиться не может.

### 3.2 Личный квадрат (ромб)

1. **A** (левая вершина, 0 лет) = R(день). Дни 1–22 берутся как есть, а 23→5, 24→6, 25→7, 26→8, 27→9, 28→10, 29→11, 30→3, 31→4.
2. **B** (верх, 20 лет) = месяц (1–12, не сворачивается).
3. **C** (правая вершина, 40 лет) = R(сумма четырёх цифр года). Пример: 1987 → 1+9+8+7 = 25 → 7. Сумма 22 остаётся 22 (1984 → 22).
4. **D** (низ, 60 лет) = R(A+B+C).
5. **E** (центр, «зона комфорта», Манипура) = R(A+B+C+D).

### 3.3 Родовой квадрат

6. **F** (левый верхний угол, 10 лет) = R(A+B).
7. **G** (правый верхний, 30 лет) = R(B+C).
8. **I** (правый нижний, 50 лет) = R(C+D).
9. **H** (левый нижний, 70 лет) = R(D+A).
10. **R** — центр родового квадрата, «аркан силы рода». Рисуется справа от E: R = R(F+G+H+I). Цитата: «получается путем сложения … углов родового квадрата»; проверено числами на схемах matrica-sudby.ru.

Диагональ F–E–I — **линия мужского рода** (род отца). Диагональ G–E–H — **линия женского рода** (род матери). Цитата: «Из левого верхнего угла в правый нижний угол направляется ось мужского рода, из правого верхнего в левый нижний — женского».

### 3.4 Внутренние точки осей (от внешней вершины к центру E)

Для каждой вершины K ∈ {A, B, C, D}:
11. **K2** = R(K+E): точка на стороне родового квадрата.
12. **K1** = R(K+K2): точка рядом с вершиной.

Только для верхней (B) и левой (A) осей:
13. **A3** = R(A2+E), **B3** = R(B2+E): точки рядом с центром (Анахата).

Цитата matrica-sudby.ru: «сложить каждую вершину с центром и записать цифру между ними. А затем … сложить вершину с полученным числом … Например, 4+6=10; 4+10=14 … от левой вершины до центра: 4, 14, 10, 6».

### 3.5 Внутренние точки диагоналей рода

Для каждого угла K ∈ {F, G, I, H} (по умолчанию):
14. **K2** = R(K+R): вторая точка от угла к центру.
15. **K1** = R(K+K2): точка рядом с углом.

Тройки записываются от угла к центру: «вверху на линии женского рода … 8-5-15» = G-G1-G2, «внизу линии 18-7-7» = H-H1-H2. Обе тройки согласуются только при R = 7, то есть с центром рода.

### 3.6 Линия талантов, каналы, кармический хвост

16. **TAL** = R(A2+B2): центр «линии талантов» (пунктир A2–B2 на уровне Вишудхи). Лежит на мужской диагонали слева сверху.
17. **X** = R(C2+D2): центр денежного канала / канала отношений. Лежит на диагонали E→I, рядом знак $.
18. **X_money** (аркан «под долларом», классика) = R(X+C2).
19. **X_love** (аркан «под сердцем», классика) = R(X+D2).
20. **Y** = R(C1+D1): третья энергия канала отношений по схеме matrica-sudby.ru (на диагонали E→I за точкой X).
21. **Кармический хвост** = три нижние энергии, код записывается от центра наружу: **D2-D1-D**. Пример: «3-22-19»: D2 = 3, D1 = 22, D = 19.

### 3.7 Предназначения

22. Небо = R(B+D); Земля = R(A+C); **Личное** = R(Небо+Земля) (реализуется до 40 лет).
23. М (мужская линия) = R(F+I); Ж (женская линия) = R(G+H); **Социальное** = R(М+Ж) (после 40 лет).
24. **Духовное** (общее) = R(Личное+Социальное) (после 60 лет).
25. **Планетарное** = R(Социальное+Духовное).

### 3.8 Карта здоровья (7 чакр × физика/энергия/эмоции)

| Чакра | Физика | Энергия | Эмоции |
|---|---|---|---|
| 7 Сахасрара | A | B | R(A+B) |
| 6 Аджна | A1 | B1 | R(A1+B1) |
| 5 Вишудха | A2 | B2 | R(A2+B2) |
| 4 Анахата | A3 | B3 | R(A3+B3) |
| 3 Манипура | E | E | R(E+E) |
| 2 Свадхистана | **C2** (вариант matrica-sudby: C1) | **D2** (вариант: D1) | R(физ+эн) |
| 1 Муладхара | C | D | R(C+D) |
| **Итого** | R(Σ физики) | R(Σ энергии) | R(итог физ + итог эн) (вариант: R(Σ эмоций)) |

В суммы «Итого» входят уже свёрнутые значения строк.

### 3.9 Возрастное кольцо (прогноз по годам, 64 точки)

Главные точки по часовой стрелке: **A (0) → F (10) → B (20) → G (30) → C (40) → I (50) → D (60) → H (70) → A (80)**.
Внутри каждого десятилетия между P0 (возраст a) и P10 (a+10):

| Позиция | Формула | Подпись (как на matrica-sudby.ru) |
|---|---|---|
| a | P0 | «a лет» |
| a+5 | mid = R(P0+P10) | «a+5 лет» |
| a+2,5 | q1 = R(P0+mid) | «a+2,5–a+3,5» |
| a+7,5 | q3 = R(mid+P10) | «a+7,5–a+8,5» |
| a+1,25 | R(P0+q1) | «a+1–a+2,5» |
| a+3,75 | R(q1+mid) | «a+3,5–a+4» |
| a+6,25 | R(mid+q3) | «a+6–a+7,5» |
| a+8,75 | R(q3+P10) | «a+8,5–a+9» |

**Аркан текущего периода.** Периоды действуют с начала подписи до начала следующей: [a; a+1), [a+1; a+2,5), [a+2,5; a+3,5), [a+3,5; a+5), [a+5; a+6), [a+6; a+7,5), [a+7,5; a+8,5), [a+8,5; a+10). После 80 лет круг повторяется (⚠ правило «второго круга» в источниках не описано, это допущение). matrica-sudby.ru предупреждает, что «для детей до 14 лет прогноз на год может быть не точным».

## 4. Справочные таблицы

### 4.1 Схема расположения точек

```
                                   B  (20 лет)              ← фиолетовая (Сахасрара, энергия)
                                   B1                       ← синяя (Аджна)
        F (10 лет)                 B2                 G (30 лет)
           F1 ┌────────────────────┼────────────────────┐ G1
               F2                  │                  G2
               │  TAL ·            B3            ·      │
               │       ·  ♂        │        ♀  ·        │
 A (0) A1 A2 ──┼─────── A3 ──────  E ─ Rod ─────────────┼── C2  C1  C (40 лет)
               │       ·  ♀        │         ·  ♂       │
               │      ·            │      X  Y          │
               H2                  │    $   ♥          I2
           H1 └────────────────────D2───────────────────┘ I1
        H (70 лет)                 D1                 I (50 лет)
                                   D  (60 лет)
```

* Ромб A–B–C–D — личный квадрат. Квадрат F–G–I–H — родовой. Точки A2, B2, C2, D2 лежат на сторонах родового квадрата; A1, B1, C1, D1 — между ними и вершинами ромба; A3, B3 — между A2/B2 и центром.
* Мужская линия (род отца): F–F1–F2–(TAL)–E–X–Y–I2–I1–I. Женская линия (род матери): G–G1–G2–E–H2–H1–H.
* Пунктир A2–TAL–B2 — линия талантов. Пунктир C2–X–D2 — канал денег/отношений (классика: $ = X+C2 между X и C2, ♥ = X+D2 между X и D2). Пунктир C1–Y–D1 — линия отношений по matrica-sudby.ru.
* Цвета чакр на схемах matrica-sudby.ru: A, B — фиолетовые; A1, B1 — синие; A2, B2 — голубые; A3, B3 — зелёные; E — жёлтый; C, D — красные; оранжевые — Свадхистана (в схемах 2021 г. на C2/D2, сейчас на C1/D1).
* Внешнее кольцо идёт по часовой стрелке от A (слева, 0 лет) вверх: F (10) → B (20) → G (30) → C (40) → I (50) → D (60) → H (70).

## 6. Контрольные точки

**Инварианты (проверяются тестами):**
* Все точки в диапазоне 1..22. B = месяц (1..12).
* D = R(A+B+C), E = R(A+B+C+D), Rod = R(F+G+H+I).
* На кольце значения в возрастах 0, 10, 20, …, 70 равны A, F, B, G, C, I, D, H. Каждая точка кольца равна свёрнутой сумме соседей уровнем выше.
* В каждой строке карты здоровья эмоции = R(физика + энергия). Строка Манипуры всегда (E, E, R(2E)).
* При свёртке сложением цифр каждый результат сравним с исходной суммой по модулю 9. Это удобно для быстрой проверки в уме.

**Типичные ошибки:**
1. Свернуть день 22 → 4: неверно, **22 остаётся 22**. Так же сумма года 22 (например, 1984).
2. Сворачивать до однозначного числа, как в «классической» нумерологии: 19 → 10 → 1. Неверно, в Матрице 1–22 не сворачиваются.
3. Свернуть месяц или ошибиться в нём: B — номер месяца как есть.
4. Сворачивать год «по паре» (19+90): неверно, складываются **четыре цифры** года.
5. Использовать в формуле несвёрнутое промежуточное значение.
6. Перепутать H и I: у нас H = D+A (левый нижний, 70 лет), I = C+D (правый нижний, 50 лет). У ask-sibylla обозначения другие (H = C+D, K = D+A).
7. Перепутать порядок цифр кармического хвоста: код пишется **D2-D1-D** (от центра наружу), например «3-22-19».
8. Смешать «прибавить 22» и «вычесть 22»: это разные школы, результаты не совместимы (см. 14.07.1992).
9. Для Свадхистаны указывать вариант (C2/D2 или C1/D1), если сверяетесь с matrica-sudby.ru.

**Граничные случаи:** день 22 (A = 22); дни 23–31; сумма цифр года > 22 (1987 → 7, 1967 → 5, 1999 → 28 → 10); сумма ровно 22 (1984); годы 2000+ (2004 → 6, 2020 → 4, 2000 → 2); 29 февраля (обычная дата, дополнительной обработки нет; для текущего возраста в невисокосный год день рождения считается 1 марта).
