# 09. Психоматрица Александрова («квадрат Александрова», цифровой анализ дат)

> Калькулятор: `calculators/alexandrov.py` (`calculate`, `compatibility`, `psychomatrix_from_groups`).
> Тесты: `calculators/tests/test_alexandrov.py`. Запуск из CLI: `python -m calculators alexandrov --date 1984-02-04 [--opt calendar=julian]`.
> Общий «генерический» квадрат Пифагора описан в документе 08. Здесь описана только авторская версия

## 1. Суть и школы

**Кто автор.** Александр Фёдорович Александров — математик (сам упоминает занятия дифференциальной
геометрией), практиковал пульсовую диагностику ✅ [DR]. Судя по упоминанию консультаций
выпускников Нижегородского театрального училища, жил в Нижнем Новгороде ⚠ (косвенно). Автор серии книг
о «цифровом анализе» дат. Термин «психоматрица» для квадрата 3×3 ввёл он сам: «я сознательно ввёл новое
название, заимствованное мною из математики — „матрица“ или „психоматрица“» ✅ [K1, «От автора»]. Первый
вариант книги вышел в 1999 г., а в 2011 г. появился вновь, «с новыми дополнениями, уточнениями и
исправлениями» ✅ [K1]. Название «квадрат Александрова» встречается в интернете, но сам автор так не
пишет. Он говорит «психоматрица», «цифровой анализ», «система Александрова анализа различных дат» ⚠.

**Суть метода.** Дату рождения записывают как ряд цифр и получают из неё 4 «дополнительных числа». Все
цифры, кроме 0, раскладывают по ячейкам 1…9. Затем каждую ячейку и каждую из 8 линий оценивают по
количеству цифр по единой 7-ступенчатой шкале. Сверх этого автор вводит несколько собственных элементов:
- переходы цифр: 22↔4, 11↔8, 6↔7 и «99 дают 5»;
- метод временных интервалов, где «сильные» линии порождают дополнительные цифры; именно так автор решает
  проблему дат после 2000 года;
- бытовую и духовную стабильность и срок стабильности брака;
- «номер жизни»;
- чтение «цели жизни» по позициям чисел (идея А. А. Рыбаковой).

**Чем отличается от генерического квадрата Пифагора (документ 08).**

## 2. Входные данные

| Поле | Обязательность | Комментарий |
|---|---|---|
| Дата рождения (день, месяц, год) | обязательна | григорианская. Время и место не используются |
| `calendar` | опция | `gregorian` (по умолчанию) или `julian`. `julian` нужен, если сверяетесь с расчётами автора для дат России до 14.02.1918 |
| `compare_generic` | опция | `True` (по умолчанию): добавляет блок `vs_generic` |
| Вторая дата (супруг) | для `compatibility` | муж и жена передаются отдельно, потому что у автора правила несимметричны (например, «4-5-6 сильнее у мужа») |

Если неизвестны время или место, результат не меняется. Если неизвестны день и месяц, автор считает по году
(988 → 25 7 7 7; 1242 → 9 9 7 7). Для этого есть `psychomatrix_from_groups([год])`.

## 3. Алгоритм

1. **Запись.** Запишите дату как «день месяц год» числами без ведущих нулей: 4 февраля 1984 → `4 2 1984`,
   30 июля 1998 → `30 7 1998`. Порядок строгий.
2. **Числовой ряд.** Это все цифры записи подряд. Для `4 2 1984` ряд такой: 4 2 1 9 8 4.
3. **Первое число** = сумма всех цифр ряда.
4. **Второе («ведущее») число** = сумма цифр первого числа, однократно. Если первое однозначное, второе
   равно ему («прибавить ноль»).
5. **Третье число** = первое − 2 × (первая цифра ряда). Первая цифра ряда — это первая значащая цифра дня.
   Если результат отрицательный, берите модуль («14 − 10 = 4»).
6. **Четвёртое число** = сумма цифр третьего, однократно. Если третье однозначное, четвёртое равно ему.
7. **Запись расчёта** в две строки: `4 2 1984` / `28 10 20 2`.
8. **Психоматрица.** Сосчитайте каждую цифру 1…9 во всех цифрах даты и четырёх чисел. Нули сосчитайте
   отдельно. Матрицу записывайте так: строки 1-4-7 / 2-5-8 / 3-6-9 (у автора «1 4 7 / 2 5 8 / 3 6 9»).
9. **Линии.** Для каждой линии сложите количество цифр в её трёх ячейках. Строки: 1-4-7, 2-5-8, 3-6-9.
   Столбцы: 1-2-3, 4-5-6, 7-8-9. Диагонали: духовная 1-5-9 и плотская 3-5-7.
10. **Оценка.** Каждая ячейка и линия оценивается по шкале (раздел 4.1) и по таблицам 4.3 и 4.4.
11. **Номер жизни** = количество цифр в матрице без нулей. По автору, не больше 15.
12. **Метод временных интервалов.**
    - Период P = (год mod 1000) div 200 + 1. Линия «сильная», если в ней не меньше P цифр.
    - Каждая сильная линия может «породить» одну дополнительную цифру в одной из своих трёх ячеек.
    - Одну и ту же линию нельзя использовать дважды. Новые цифры не вписывают в матрицу как
      существующие, это только потенциал развития.
    - Для каждой ячейки максимум дополнительных цифр равен числу сильных линий, которые через неё проходят.
13. **Стабильность.**
    - Бытовая: БС = А×Б×В, где А = плотская диагональ 3-5-7, Б = строка 3-6-9, В = строка 2-5-8.
    - Духовная: ДС = Г×Д×Е, где Г = диагональ 1-5-9, Д = столбец 1-2-3, Е = строка 1-4-7.
14. **Совместимость супругов** (необязательно).
    - БСС = БСмужа × БСжены. ДСС = ДСмужа × ДСжены.
    - Период бытового кризиса = round(БСС/365) лет. Период духовного кризиса = round(ДСС/365).
    - ОСС = сумма двух округлённых значений.
    - Пара критическая, если периоды равны или кратны. Брак стабилен, если ОСС ≥ 50–60 лет.

```
def alexandrov(d, m, y):
    record = f"{d} {m} {y}"                  # без ведущих нулей
    row = [int(c) for c in record if c != " "]
    n1 = sum(row)
    n2 = digit_sum(n1)                        # однократно
    n3 = abs(n1 - 2*row[0])                   # row[0] — первая значащая цифра дня
    n4 = digit_sum(n3)
    digits = row + digits_of(n1, n2, n3, n4)
    counts = {k: digits.count(k) for k in 1..9}; zeros = digits.count(0)
    lines = {L: sum(counts[c] for c in cells(L)) for L in 8 линий}
    P = (y % 1000)//200 + 1
    strong = [L for L in lines if lines[L] >= P]
    BS = lines[357]*lines[369]*lines[258];  DS = lines[159]*lines[123]*lines[147]
    life_number = sum(counts.values())
```

### 4.5. Метод временных интервалов ✅ [K1 гл. 12; TMC гл. 1]

| Период | Годы | Минимум цифр в «сильной» линии |
|---|---|---|
| 1 | 0–199, 1000–1199, 2000–2199 | 1 |
| 2 | 200–399, 1200–1399, 2200–2399 | 2 |
| 3 | 400–599, 1400–1599, 2400–2599 | 3 |
| 4 | 600–799, 1600–1799, 2600–2799 | 4 |
| 5 | 800–999, 1800–1999, 2800–2999 | 5 |

Правила [DR, «Влияние линии психоматрицы на цифры»; TMC]:
- сильная линия может «породить» только одну из трёх своих цифр;
- одну линию нельзя использовать повторно;
- созданные цифры не вписывают как имеющиеся: «нужно время, иногда не один год»;
- создание происходит только при работе человека над качеством линии; при деградации и властных
  устремлениях оно невозможно.

### 4.6. Переходы цифр ✅ [DR «Переходы цифр»; TMC гл. 3]

| Переход | Количественная запись | Когда (по автору) |

| 8 → 11 | 8 переходит в 11 с потерей 22 или 4 | волевое стремление к власти; сопровождается 7 → 6 |
| 6 ↔ 7 | 1 : 1 | 6 → 7: искусство, чтение, терпимость; 7 → 6: потеря долга к родителям |

## 6. Контрольные точки

**Инварианты.** Все они проверяются тестом на датах 1900–2100.
- Сумма количеств по ячейкам плюс число нулей равна числу цифр в записи даты и четырёх чисел.
- Номер жизни ≤ 15. Перебор всех дат 1000–2999 даёт максимум 15 (29.12.1149), что совпадает с утверждением
  автора «больше 15 цифр не будет».
- Третье число ≥ 0 (модуль).
- Каждая линия равна сумме своих трёх ячеек. Ячейка 5 входит в 4 линии; 1, 3, 7, 9 входят в 3; 2, 4, 6,
  8 входят в 2.
- Для дат 1000–1999 цифра 1 всегда есть, для дат 1900–1999 всегда есть и 9. Поэтому «1-нет» встречается
  только после 2000 г., а «9-нет» для XX века у автора «невозможный случай».
- `max_extra_total` равен числу сильных линий.

**Типичные ошибки.**
1. Ставить ноль перед днём или месяцем. Для 04.02.1984 получится 28 − 0 = 28 вместо 20.
2. Доводить второе или четвёртое число до однозначного. Правильно 19 → 10, а не 1.
3. Применять «+19» к датам после 2000 г. У Александрова такого правила нет.
4. Вписывать «созданные» сильными линиями цифры в матрицу как реальные.
5. Путать ориентацию матрицы. У автора ячейки идут столбцами: 1-2-3 | 4-5-6 | 7-8-9, а «строка» — это
   1-4-7.
6. Брать григорианскую дату, сверяясь с авторскими разборами Петра I или Ленина: там старый стиль.

**Граничные случаи.**
- День 1–9: первая цифра ряда — это сам день (7 1 2000 → 2×7).
- День 10, 20, 30: первая цифра 1, 2, 3 (Пётр I: 30 → 3).
- Отрицательное третье: 7.1.2000 → |10 − 14| = 4. Нулевое третье: 3 1 2000 → 6, 6, 6 − 2×3 = 0, 0 (нули
  идут в счёт нулей).
- 29 февраля считается обычным образом (T3).
- Год, кратный 200, — граница периода, будет предупреждение.
- Запись только года (события): `psychomatrix_from_groups([988])`.

⚠ **Расхождения внутри книг автора, выявленные при сверке:**
1. [K1 гл. 12; PK; DR] для 1 1 2000 пишут «Цифра 4 — одна цифра». Однако через ячейку 4 проходят две
   сильные линии (1-4-7 = 4 цифры и 4-5-6 = 2 цифры), а по правилу «каждая линия — одна цифра» получается
   до двух. Калькулятор выдаёт 2.
2. [TMC гл. 1] для 15 8 1957 перечисляет 4 сильные линии и пропускает первую строку «11 4 77», в которой
   тоже 5 цифр. Калькулятор выдаёт 5 линий.
3. [TMC гл. 1] для 30 7 1998 печатает в ячейке 7 одну семёрку, хотя их две (месяц 7 и число 37).
   Вероятно, опечатка.
4. Граница периодов: «0–199» [K1, TMC] против «1–200» [DR] (см. 4.5).

## 8. Ключи интерпретации

| Элемент | Ключ (1–2 строки) |
|---|---|
| 1-е число | качества, которые нужно развить для достижения цели («будущее») ✅ |
| 2-е («ведущее») число | ведущее качество и основная цель появления в мире ✅ |
| 3-е и 4-е числа | качества, данные от рождения, «во многом определили родители» (прошлое) ✅ |
| Цифры даты, читаемые с конца | «настоящее»: набор качеств для повседневной жизни ✅ (идея А. А. Рыбаковой) |
| Ячейка 1 | характер, воля, власть; шкала от «1 спорщик» до «11111 деспот» |
| Ячейка 2 | энергия действия и общения; «2-нет» вампир … «2222+» донор |
| Ячейка 3 | интерес к наукам и технике; «нет» — гуманитарий |
| Ячейка 4 | здоровье, тело, внешняя привлекательность |
| Ячейка 5 | логика, интуиция, планирование; 55 — сильная логика |
| Ячейка 6 | физический труд, мастерство; 666+ — «заземление», власть |
| Ячейка 7 | везение, познание мира; 777+ — «инженер жизни» |
| Ячейка 8 | долг к родителям, терпимость, доброта; 88+ — правдоискатель |
| Ячейка 9 | память, ум; 999+ — ясновидение |
| Цифра 0 | вне матрицы; истина/Пустота или потеря/пустота; читается по позиции (например, 3-е число 10/20/30) |
| Строка 1-4-7 | целеустремлённость |
| Строка 2-5-8 | качество семьянина |
| Строка 3-6-9 | стабильность и привычки; 0–3 — «революционер» |
| Столбец 1-2-3 | самооценка (автор подчёркивает: не эгоизм) |
| Столбец 4-5-6 | обеспечение семьи, быт, работа |
| Столбец 7-8-9 | талант, внутренний потенциал |
| Диагональ 1-5-9 | духовность; 6+ — фанатизм |
| Диагональ 3-5-7 | темперамент, плотские потребности |
| Номер жизни | количество цифр без нулей = «какую жизнь проживает душа» (≤15). Автор: «если вам это нравится — пользуйтесь» |
| БС / ДС | «объём» бытовой и духовной стабильности, вклад человека в стабильность брака |
| Сильная линия | линия с числом цифр ≥ номера периода. Может «породить» одну недостающую цифру при работе над качеством |
| Переходы | 11→8 и 6→7 «положительные» (терпимость, творчество; награда 22/4); 8→11 и 7→6 «отрицательные» |

⚠ Не реализовано и не рекомендуется к автоматической выдаче:
- «отслеживание порчи» по балансу 7/8 против 6 у родителей и детей [DR] — этически чувствительно;
- диагностика болезней по У-син.

Всё это нумерология, научной валидности у неё нет. Калькулятор воспроизводит систему автора, а не факты.
