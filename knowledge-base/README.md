# База знаний: расчёты по дате рождения — инструкция для ИИ-агента

Эта папка — основа для агента, который по запросу пользователя выполняет расчёты по 16 системам
(астрологическим, китайским, нумерологическим и типологическим). Каждый файл `NN-*.md` описывает
один метод по единому шаблону (суть → входные данные → алгоритм → таблицы → JSON-выход →
контрольные точки → разобранные примеры → ключи интерпретации → источники → протокол проверки).
Рядом лежат эталонные калькуляторы на Python (`calculators/`), которые воспроизводят каждый пример
из документов и покрыты тестами (`pytest`).

> **Статус знаний.** Все перечисленные системы — эзотерические или типологические практики без
> научного подтверждения предсказательной силы. Агент считает их **точно по правилам школы** и
> честно сообщает о вариантах и неопределённостях. Медицинские, финансовые и юридические решения
> на этих расчётах не строятся.

## 1. Что спросить у пользователя (чек-лист)

| Поле | Зачем | Как уточнять |
|---|---|---|
| **Дата рождения** | все методы | Формат ДД.ММ.ГГГГ. Для рождений в России **до 14.02.1918** спросить, по какому стилю дата (в документах того времени — юлианский, «старый стиль»). Перевод: CLI `--calendar julian`, Python `BirthInput(…, calendar="julian")`, вручную +12 дн. (ст. ст. 01.03.1800–28.02.1900) или +13 дн. (29.02.1900–31.01.1918). |
| **Время рождения** | Ба-цзы (час), Цзы Вэй, Human Design, Gene Keys, западная астрология, Джйотиш | Спросить **источник** (свидетельство, со слов, «утром») и точность. Без времени — см. §4. |
| **Место рождения** | всё, где нужно время | Город + страна → координаты + историческая IANA-зона. Для СССР — именно город **и регион на дату рождения** (АССР/область/край): для ряда регионов tzdb неточен (регионы-«нарушители» 1981/82, Туркмения 1991/92, Крым, Поволжье и др. — табл. 4.11 модуля 00). CLI: `--region «Татарская АССР»`; альтернативное смещение — в поле `alternatives`. |
| **Пол** | Цзы Вэй, Ба-цзы (направление столпов удачи), число Гуа | Как в документах / по самоопределению — спросить. |
| **ФИО** | нумерология имени (11), имя в Сюцай (15), халдейское число (12) | Полностью, как в свидетельстве о рождении; для текущего имени (после брака) — отдельно. Латиницей — если пользователь так хочет считать. |
| **Анкета** | соционика и эннеаграмма (14) | **По дате не вычисляются!** Провести опросник из модуля 14. |

## 3. Порядок работы агента

1. **Собрать входные данные** по чек-листу §1. Не додумывать время/место.
2. **Нормализовать время** (модуль 00): локальное время → историческое смещение по tzdb (летнее/декретное время СССР!) → UTC → юлианский день. До введения поясного времени — LMT по долготе **места** (не столицы зоны). Старый стиль → григорианский.
   Проверка (из корня репозитория): `.venv/bin/python -m calculators time --date … --time … --place …`.
3. **Посчитать каждый запрошенный метод** по его документу (раздел «Алгоритм»), а при наличии Python — калькулятором:
   `.venv/bin/python -m calculators all --date 1990-05-15 --time 14:30 --place Москва --gender female --name "Иванова Анна Сергеевна"`.
   Опции методов (школа, вариант, система домов и т.д. — перечислены в документах):
   - для одного метода — `--opt ключ=значение`, напр. `bazi … --opt solar_time=clock`;
   - для `all` — с префиксом метода: `--opt bazi.solar_time=clock --opt western.hsys=K` (без префикса в `all` опции игнорируются, считаются умолчания).
4. **Самопроверка** — пройти раздел 6 «Контрольные точки» документа метода и межмодульные проверки (§5).
5. **Выдать результат** по шаблону §6. Обязательно указать **школу/вариант**, предупреждения (`warnings`),
   чувствительность ко времени и альтернативы там, где школы расходятся.
6. **Интерпретация** — только по таблицам раздела 8 «Ключи интерпретации», без выдумывания.

## 4. Если время, место или пол неизвестны

| Метод | Без времени | Без места (время известно) |
|---|---|---|
| Ба-цзы (01) | 3 столпа (год, месяц, день), столп часа не строится. Год/месяц — на конец местной даты (день цзе/Личуня = новый период, как в 03 и 12) + предупреждение и оба варианта | нужен хотя бы `--tz`; без долготы истинное солнечное время невозможно → время часов + предупреждение |
| Цзы Вэй Доу Шу (02) | **полный чарт не строится** — калькулятор даёт частичный результат и 12 вариантов по часам | нужен `--tz`; без долготы — время часов (предупреждение) |
| Девятизвёздная Ки, Гуа, зодиак (03) и Гуа в 12 | год считается; **в день Личуня** (и для звезды месяца — в любой день цзе) нужен час и пояс, иначе день цзе = новый период + предупреждение | пояс (иначе сравнение по UTC+8) |
| Human Design / Gene Keys (04, 05) | только неизменное за сутки: поле `time_sensitivity` (HD) / `time_scan` (GK); Луна, профиль, тип, авторитет могут меняться | нужна зона для UTC |
| Западная астрология / Джйотиш (06, 07) | нет домов, Асцендента, MC; Луна ±6–7°; возможные знаки Солнца за день — `possible_signs_ru` (06) / `moon_range_for_day` (07) | нет домов/Асцендента; без `--tz` расчёт невозможен |
| Цолькин (13) | считается; 29.02 без времени → кин 28.02 по умолчанию, кин 01.03 — альтернатива (правило полудня) | — |
| Нумерология (11), психоматрицы (08, 09), Матрица (10), Таро/Ло Шу/вед. нумерология (12, кроме Гуа), Сюцай (15) | не нужно | не нужно |

**Без пола:** Ба-цзы — нет столпов удачи; Цзы Вэй — нет направления десятилетий (декад); Гуа — даётся для обоих полов.

CLI откажется считать, если время задано без пояса (`--place`, или `--lat/--lon` — зона определится по координатам, или `--tz`).

## 5. Межмодульные согласования (проверять при «all»)

- **Год по Личуню** одинаков в Ба-цзы (01), Ки/зодиаке по солнечному году (03) и Гуа (03 = 12) — тест `test_cross_year_boundary.py`. Китайское «животное года» в популярных гороскопах считают по **лунному Новому году** — это другая граница; модуль 03 показывает обе (`zodiac_lunar` / `zodiac_solar`).
- **Цзы Вэй (02)** по умолчанию: год по лунному Новому году, поздний час Цзы (23–24) переносит дату на следующий день (`zi_hour=next_day`); **Ба-цзы (01)**: год по Личуню, поздний Цзы остаётся в той же дате (`late`). Поэтому для T2 по часам Цзы Вэй относит рождение к 4-му дню лунного месяца, а Ба-цзы сохраняет день 04.02 — это ожидаемо.
- **Знак Солнца** в западной астрологии (06) = знак Солнца Личности в HD (04) (тропический зодиак); в Джйотиш (07) — сидерический, сдвиг на аянамшу Лахири: ≈22,2° (1879) … 24,2° (2026).
- **Лунные узлы:** в Джйотиш (07) по умолчанию **средний** узел, в HD/Gene Keys/западной (04, 05, 06) — **истинный** (разница до ~2°).
- **Ворота HD (04) = Генные ключи (05)** для всех общих тел (тест `test_cross_hd_gk.py`).
- **Рабочие числа Пифагора (08) и Александрова (09)** совпадают по умолчанию (оба не удваивают ведущий ноль дня).
- **Халдейская таблица** в 11 и 12 одинакова (тест). В модуле 12 `compound` = сумма всех букв; в модуле 11 `compound` = сумма по словам по Хейро — значения согласованы, названия полей разные.
- **Арканы 8 и 11:** в Матрице судьбы (10) — 8 Справедливость, 11 Сила (традиция школы Ладини / Марсель); в Таро по дате (12, колода RWS) — 8 Сила, 11 Справедливость. Называть аркан по системе модуля.
- **Число сознания/миссии Сюцай (15)** = Мулянк/Бхагьянк ведической нумерологии (12); планеты 1–9 совпадают.
- **Кин Dreamspell (13)** ≠ классический день цолькина: разница растёт на 1 с каждым 29 февраля. Не смешивать.
- **卯** в разных модулях назван «Кролик (Заяц)» / «Кролик (Кот)» / «Кролик» — это одна и та же ветвь.

## 6. Шаблон ответа пользователю

- Язык — русский; оригинальные термины — в скобках (庚午, Projector, Uttara Ashadha…).
- Порядок блоков: входные данные и нормализация (00) → китайские системы (01, 02, 03) → астрологические (04, 05, 06, 07) → числовые (08, 09, 10, 11, 12, 15) → Цолькин (13) → типология (14, только анкета).
- В каждом блоке: (1) вариант/школа (`variant`); (2) главный результат; (3) ключевые шаги (`steps`) — кратко, чтобы пользователь мог проверить; (4) расхождения школ — `alternatives` (01), `time_alternatives`/кандидаты (02), `life_path_by_method` (11), `zodiac_lunar`/`zodiac_solar` (03), `comparison` (13); (5) чувствительность ко времени и предупреждения; (6) интерпретация — только из раздела 8 документа.
- Для текущих циклов (личный год, даша, столпы удачи, возрастные точки) **называть дату, на которую посчитано**: по умолчанию — сегодня (`on_date` в 07, `year`/`target_year` в 11, 12, 15); в Матрице судьбы (10) текущий период выдаётся, только если задан возраст/дата.

## 7. Если Python недоступен (расчёт вручную)

- **Точно вручную:** 08, 09, 10, 11, 12, 13, 15 (арифметика по таблицам документов), столп дня Ба-цзы (формула JDN), год/месяц Ба-цзы и Ки — если известны моменты цзе (таблицы HKO, формула в 01 §3 с точностью ±12 мин).
- **Нужны эфемериды:** 04, 05, 06, 07 и час/месяц на границах в 01–03. Без программы/эфемерид **не придумывать позиции планет** — честно сказать, что нужен расчёт, или дать приблизительные оценки с явной погрешностью (методы ручной оценки — в документах 06 и 07).
- **Соционика и эннеаграмма** — опросник и подсчёт вручную по документу 14 (или `from calculators.typology import get_questionnaire, score_socionics, score_enneagram`).

## 8. Ограничения

- Файлы Swiss Ephemeris покрывают 1800–2399 гг.; вне диапазона — аналитическая теория Moshier (точность ниже), Хирон пропускается, Матрица судьбы (10) предупреждает.
- Справочник городов `common/places.py` знает ~30 городов; для остальных — `--lat --lon` (зона определится по координатам через timezonefinder) или явный `--tz`. tzdb надёжен после 1970 г.; до этого — только для эталонного города зоны (см. 00).
- Ба-цзы не меняет месяцы для южного полушария (школы расходятся — см. 01).
- Цзы Вэй использует китайский календарь (UTC+8) по местной дате рождения; у рождений около новолуния лунный день может отличаться (калькулятор предупреждает).
- CLI принимает секунды (`--time HH:MM:SS`) и старый стиль (`--calendar julian`).
- Это эзотерические системы: тесты подтверждают **соответствие правилам школ и опубликованным расчётам**, а не «истинность» выводов.

## 11. Правила честности

- Ничего не выдумывать: если правило школы не подтверждено, в документах стоит «⚠ не подтверждено» — так и сообщать.
- Всегда называть вариант/школу и альтернативу, если результат от неё зависит.
- Соционика и эннеаграмма по дате **не считаются**; «соционика по дате» — неканонично и выдаётся только по явной просьбе с пометкой.
- Не путать системы с похожими названиями: Dreamspell-кин ≠ майяский день; Сюцай ≠ Ба-цзы; квадрат Александрова ≈ квадрат Пифагора (различия — в модуле 09).
